1. PROBLEM
================================================================================
MCP (Model Context Protocol) is the JSON-RPC 2.0 standard for AI agent-to-tool
communication. Adopted by Claude, GPT, Cursor, and hundreds of AI platforms.

The attack surface:
  * 200,000+ MCP server endpoints exposed on the internet (Shodan/Censys, 2025)
  * 36% have zero authentication — default SDK binds to 0.0.0.0
  * 30+ CVEs in 2025-2026 (per OWASP MCP Top 10, NVD)
  * First malicious MCP package (postmark-mcp) found in the wild
  * Tool arguments passed unsanitized to shell commands, file ops, SQL queries
  * Tool descriptions can contain prompt injection payloads

The OWASP MCP Top 10 was published in 2025. No comprehensive offensive tool
exists to systematically test for these vulnerabilities.

================================================================================
2. MCPWN
================================================================================
6,114 LOC · 32 tests · Python 3.8+ · zero dependencies

2.1 MCP Protocol Client
Full JSON-RPC 2.0 implementation over HTTP+SSE and stdio transports.
Handles initialization, capability negotiation, tool/resource/prompt
enumeration, and tool invocation.

2.2 Network Scanner
  * Common MCP ports: 3000, 3001, 5000, 8000, 8080, 9000
  * Standard endpoints: /mcp, /sse, /api/mcp
  * Multi-threaded subnet scanning
  * Auth detection and server fingerprinting

2.3 Automated Security Auditor (9 vulnerability classes)
  * Path traversal (CWE-22): 12 payload variants
  * Command injection (CWE-78): 15 payloads
  * SSRF (CWE-918): AWS/GCP/Azure metadata, file://, gopher://
  * SQL injection (CWE-89): UNION, time-based blind, error-based
  * Arbitrary file write (CWE-73)
  * Missing authentication (CWE-306)
  * Tool poisoning (CWE-94): 8 prompt injection patterns
  * Sensitive data exposure (CWE-200)
  * Prompt injection via tool responses

2.4 Attack Framework
  * Data exfiltration: SSH keys, AWS creds, .env files via file-reading tools
  * Resource URI injection: file://, cloud metadata, internal IPs
  * Response injection: manipulate AI agent behavior
  * Privilege escalation: access admin tools without auth
  * Tool poisoning analysis: detect prompt injection in tool descriptions

2.5 CVE Database
  * CVE-2025-49596: MCP Inspector RCE (CVSS 9.4)
  * CVE-2026-27825: mcp-atlassian arbitrary file write → RCE
  * Server fingerprinting for automated CVE matching

2.6 Vulnerable Test Server
Intentionally vulnerable MCP server with all 9 vulnerability classes.

2.7 Forensic Logger
MCP traffic capture with SHA-256 integrity chains, anomaly detection.

================================================================================
4. PRIOR ART
================================================================================
  * OWASP MCP Top 10 — risk taxonomy, no tooling
  * MCP Inspector — debugging tool (itself had RCE, CVE-2025-49596)
  * Manual pentesting — per-engagement, not systematic

MCPwn is, to our knowledge, the first open-source framework for systematic
MCP security testing.
